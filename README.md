## 二、源码学习与交易系统理解

底层 `MdApi`、`TdApi` 分别处理行情和交易柜台回调。VeighNa 网关把柜台字段转换为统一行情、订单、成交等对象；事件引擎把事件分发给订单管理缓存和策略引擎；主引擎按网关路由交易请求。委托请求返回成功只表示请求已被接收，订单受理和实际成交仍需后续回报确认。[三层架构图](wiki/concepts/architecture.md)记录了这条数据与委托链。

单标的 CTA 策略维护单合约时序状态；多标的投组策略需要同步截面、目标权重和总风险预算；价差策略还需协调两腿订单及裸露风险。`vnpy_ctastrategy` 的源码阅读重点是第一类；投组与价差部分根据主框架文档学习，没有声称已安装、开发或联网验证相应应用。源码范围和具体提交号见[三个摘要页](wiki/index.md)及[提交记录](reports/source_commits.json)。

## 三、底层 CTP 演示与现场验证

演示程序直接使用 CTP Python API 的回调，完成连接、交易终端认证、登录、合约订阅和逐条行情打印。默认不会自行退出；`--duration 60` 只用于限时验证。断线时清理连接状态，重连后重新登录与订阅；无效价格不会作为正常报价显示。程序不包含发单或撤单功能。

2026 年 9 月 23 日 00:19—00:20 的本机 SimNow 复验中，行情和交易通道均登录成功，交易终端认证成功，4 个合约订阅回报成功，60 秒收到 **202 条行情回调**。黄金 `au2612` 82 条、白银 `ag2612` 93 条、铜 `cu2610` 26 条，均观察到交易所时间及累计成交量变化；螺纹钢 `rb2701` 仅 1 条上一时段快照，不能称为持续活跃。没有对全市场成交量排名，因而不声称这些合约就是各品种成交量第一的主力合约。[现场报告](reports/ctp_live_20260923_retry01/report.md)附有[逐合约核验](reports/ctp_live_20260923_retry01/verification.json)与[原始回调](reports/ctp_live_20260923_retry01/events.jsonl)，[汇总](reports/ctp_live_20260923_retry01/summary.json)记录 `orders_sent=0`。

## 四、第一轮跳空因子实验

使用课程包内的股票日线缓存：**819 只股票、2,668,723 行**。价格和量能候选均在交易日 (T) 收盘后形成，预测标签为下一交易日收盘至第三交易日收盘的收益；按全市场交易日历对齐，排除缺失端点和越过分段末尾的标签。方案先于本轮统计固定：2008—2016 年训练、2017—2018 年验证、2019 年至 2020 年 8 月历史测试；只用训练期选择候选，测试期不回改规则。[方案](reports/gap_round_01_v2/protocol.md)和[数据审计](reports/gap_round_01_v2/data_audit.json)给出细节。

16 个候选覆盖直接跳空、累计跳空、意外跳空、波动缩放、方向一致性、量能确认及隔夜/日内分解。训练期规则选中 `g16_gap_intraday`，即“过去 5 日的隔夜收益减日内收益的均值”。其日均**股票排序相关**如下；它不是收益率：

|分段|有效交易日|日均排序相关|时间相关稳健 95% 区间|
|---|---:|---:|---|
|训练|2,187|0.04195|[0.03386, 0.05005]|
|验证|484|0.03119|[0.01362, 0.04877]|
|历史测试|402|0.01585|[-0.00205, 0.03375]|

该因子通过事先设定的验证期标准，历史测试信号减弱且区间跨零。它含日内反转成分，不能称为纯开盘跳空延续。全部 16 个候选及负面结果见[逐因子报告](reports/gap_round_01_v2/report.md)和[统计原表](reports/gap_round_01_v2/metrics.json)。原缓存年份已被课程研究过，这一“历史测试”不是全新独立样本验证；排序相关也不能解释为扣除成本后的可交易收益。

## 六、结论与交付边界

第二讲 Issue 的 Wiki、源码学习、行情演示、系统架构理解、下单方案及一轮跳空因子均已有对应成果和可核验证据。**价格触发下单没有执行**；这符合 Issue “先给方案，等阅读确认后再执行”的要求。现场行情成功限于上述 60 秒与实际更新的三个合约，不能外推为全天稳定运行。

课程包提供的是历史缓存，未从行情供应商独立重建全部原始行情、复权和历史股票池；停复牌、涨跌停、退市与实际成交成本等约束也未形成可执行净收益评估。后续研究应使用真正未参与本系列探索的新时间段，并预先固定交易与评价规则。
