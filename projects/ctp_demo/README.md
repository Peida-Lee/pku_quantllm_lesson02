# 底层 CTP 行情作业

安装与当前 Python 版本匹配的 `vnpy_ctp` 后，从仓库根目录执行 `python projects/ctp_demo/demo.py`，默认持续输出直到 Ctrl+C。追加 `--duration 45` 可限定验证时间；`--offline` 为合成回放，明确与现场行情区分；`--md-only` 只连接行情接口。

实现连接、终端认证、登录、订阅、逐条行情、心跳和重连重订阅。行情打印最新价、买卖一档、成交量、持仓量及交易日/自然日。DBL_MAX、非有限值与非正价格显示为 null。每次报告另建目录，拒绝覆盖。

先复制 `config.example.json` 为 `config.simnow.local.json` 并填写自己的仿真账号；后者已被 Git 忽略，不在公开仓库。也可用 SIMNOW_PASSWORD 环境变量覆盖密码。演示合约是按月份选取的候选，无法仅凭名称保证为当前主力，应据实际行情和交易所合约表复核。
