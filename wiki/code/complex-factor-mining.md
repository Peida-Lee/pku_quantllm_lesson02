# 复杂价量因子与集成模型第二轮

[index](../index.md) · [overview](../overview.md) · [large-factor-mining](large-factor-mining.md)

本轮按固定五小时预算在2号服务器运行，状态为**部分完成**。搜索阶段完成60,000条公共候选、111,891个唯一表达式及10折各192个新增因子；传统岭回归、LightGBM和XGBoost完成360次调参与168个最终模型。AutoGluon实际采用官方`medium_quality`、`high_quality`，完成51/80个候选与40/41个最终重拟合；计划内未完成项不能视为成功。

10折均按“只使用测试期之前的数据训练、连续两年测试”完成外层评价。208个最终模型通过独立重载核验，1个已选模型缺失；另有2折的复杂输入`high_quality`候选未完成。5个不重叠主折的验证期选出组合日均排序相关为0.07566。固定LightGBM下，扩展输入相对上一轮的日均排序相关差为+0.00056，95%区间[-0.00126, +0.00238]，不能据此认定新增因子带来稳定提升。

发现期选择轨迹14,887条及入选公式完整向量1,871条重放通过；本地归档、1,158个文件及来源输入哈希通过核验。完整报告：`reports/complex_factor_mining_20260923/report.md`；本地接收凭据与完整交付文件未公开；运行方案与代码保留在本地交付目录。模型与行级预测保留在2号服务器。历史年份已多次研究，仍需未来新数据验证，排序相关不能解释为可执行净收益。
