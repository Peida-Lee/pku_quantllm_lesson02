# 大规模价量公式挖掘

[index](../index.md) · [overview](../overview.md) · [stock-multifold](stock-multifold.md)

大规模价量公式挖掘已完成：35,375个唯一表达式、10折每折128个新增因子，370次内层拟合、171个最终模型。固定提升树中新增因子的日均相关增量为+0.0034，95%区间[+0.0012, +0.0055]；验证期选择的组合相关为0.0760。属于历史内部研究。

公共生成不看收益；演化、去重、方向只用各折发现期，随后分别验证因子和模型，最后测试连续两年。主统计拼接5个不重叠窗口，另外5折用于窗口敏感性。固定参数的原80、仅新增和合并输入对照单列，避免混入调参效果。

2号服务器执行并通过公式重算、预处理及模型重放、逐日指标复核和选择轨迹重放。首次模型启动的临时目录权限失败发生在拟合前，独立保留，修复后复用原搜索。
