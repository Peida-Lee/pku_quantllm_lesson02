## ST 与涨跌停的可知边界

包内没有历史 isST、证券名称变更、官方交易状态、逐日官方涨跌停价、上市与退市生效日。真实历史ST已知格数为0。不得用当前ST名单回填历史，不得把“过去出现5%附近封板”写成“真实ST已识别/已剔除”，不得将当前未知填成非ST。

可以预先指定一个**历史价格风险代理**：仅对代码规则判为主板的证券，检查信号日及之前固定窗口内是否出现接近0.01元半入计算的±5%候选价且收在当日高/低点的现象；剔除或单独标记复权因子跳变日。代理使用的最大日期必须不晚于信号日，所有窗口和容差在实验前固定。它只能表示过去价格行为，不能标定ST身份。

主要误差包括：普通股票也可能恰好在5%附近收于高/低点；真实ST未必在过去窗口触及限价；撤销/新增风险警示会改变状态；累计复权因子不能给出官方除权参考价；0.01元舍入、特殊无涨跌幅日与限价规则可能不同。`high==close` 或 `low==close` 也不等于全天一字锁板，一字价格特征至少还需要OHLC全部相同，但即使相同也无法证明真实排队成交。

统一4.8%门禁不保证覆盖所有主板理论5%边界：例如参考价2.09，候选上价按0.01半入为2.19，涨幅约4.785%，未达到4.8%；参考价2.10，候选下价为2.00，跌幅约4.762%，也未达到−4.8%。因此更稳妥的未知状态保守情景应同时检查半入后的候选5%上下价边界，并继续标为候选而非官方限价。不能用结果收益选择代理窗口或容差后再称确认性ST过滤。

严格要求真实历史ST已知的模式应拒绝启动或拒绝未知证券买入，并明确“没有可用真标签”；仅包内模式必须另行命名为代理/保守情景。

## 成交容量来源

唯一容量字段为 `amt`（成交额）。没有成交股数、盘口、买卖队列、开盘竞价成交量或逐笔数据。课程包数值元数据未明确货币单位，本审计保留“压缩包数值单位”；引擎若按元使用1000万元门槛，属于须公开的计量假设，不能以数值看似合理当作官方单位核验。

可在交易日开盘前由包内历史确定的代理为：前20个课程日期全部非缺失的成交额均值，整体滞后一期；配合前20日正成交额天数。它不是开盘深度。

|---|---:|---:|
| 前20日均额可计算格数 | 1,249,610 | 5,214 |
| 示例门槛后格数（均额≥10,000,000且活跃日≥15） | 1,244,113 | 5,182 |

| 再取当日最终amt的1%上限后中位数 | 1,081,947.089 | 830,406.315 |

数量均为包内数值单位，不代表可实际成交金额。示例门槛不是新增参数择优，也没有把它解释为已剔除ST。

`min(过去20日均额×比例, 当日最终成交额×比例)` 是**事后全日容量上限情景**。当日最终成交额在开盘时不可知；即使只用于限制成交量而不进入信号，也不能据此宣称开盘成交模型完全因果或真实可执行。同一证券当日多次买卖必须累计占用上限，不能逐笔重置容量。若交易价格仍按开盘模拟，必须单列“开盘价与全日容量并用”的限制。

## 引擎方案独立审查与验证思路

1. 信号与目标用t日已知收盘NAV、价格和历史窗口冻结；只在t+1以后尝试交易。未来数据扰动不得改变此前信号、候选名单或目标数量。禁止用全年风险代理名单倒推过去。
2. 真实ST与官方状态保持未知；代理另列字段。主板/创业板/科创等代码分类只作规则假设，未知市场不得静默套主板10%。本包没有BJ代码，这不能成为通用代码忽略BJ的理由。
3. 理论价使用明确0.01半入、相同参考价与可核查边界；测试边界附近价格和低价舍入，不以4.8%阈值替代官方状态。没有官方真值时不能报告ST准确率、误判率或官方限价覆盖率。
4. 当日cumadj跳变拒单是来自日终字段的事后安全情景；除非另有时点公告，不得说盘前已知官方公司行为。累计因子也不能恢复真实分红现金、送转交收和税费。
5. 可验证资金、费用、整手、T+1、容量累计和净值等账本恒等式；它们不能验证竞价队列、开盘撮合或真实冲击成本。使用小型手算、前缀扰动和场景敏感性，而不是用同一实现生成预期值。
6. 期末不能虚构无条件清仓。冻结清仓目标后若受限，应保留残仓及拒单原因；没有官方退市事件时，缺价减记是估值情景，不是真实退市清偿。

因此本包可以支持更严格且可审计的日线研究账本，不能单独支持“已剔除真实ST”“官方涨跌停精确撮合”“真实退市清算”或“开盘成交高精度验证”的结论。
