# 课程要求及本次运行范围

来源：https://github.com/aslan9/pku_quantllm/issues/8 。2026-10-16（Asia/Shanghai）通过本机官方Browser运行时、Edge扩展读取实际页面。

原文作业要求：

1. 实现在非ST股票上的全市场选股。
2. 假设初始资金10亿人民币。
3. 交易费用：佣金单边万一；印花税万五。
4. 从2025年第一个交易日（当日开始建仓）到2026年9月最后一个交易日（当日清空离场）。

本次用户直接指定2025年第一个交易日至最后一个交易日，且确认唯一数据为`D:\quant\feathers.zip`。因此主研究采用2025-01-02至2025-12-31；同时对2024选型的入围参数提供作业延伸2025-01-02至2026-09-30。延伸不是用2025结果再次挑选参数。

原包不提供历史ST身份。价格风险代理与未知状态保守门禁可用于敏感性研究，但不能据此声明实现了真实非ST全市场。末日只能在模型约束下发起清仓，未成交的残仓必须另列。因此这两条作业要求的真实市场完成性无法仅从原包证明。

佣金1bp、卖出印花税5bp沿用作业；最低佣金5元、过户费0.1bp、不利价格刻度后的滑点及容量限制是额外执行假设。另列关闭滑点、零费用、压力费用与收紧容量场景，不能把零费用当作业含费结果。
