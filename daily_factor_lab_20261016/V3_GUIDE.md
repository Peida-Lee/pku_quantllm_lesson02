## 本轮研究

- 主区间：2025-01-02至2025-12-31，课程矩阵实际243日。
- 选型区间：2024-01-02至2024-12-31。由于V1已看过含2025的全区间，这是一项回顾性时间分段，不能宣称2025从未触碰。
- 作业补充：对2024入围策略运行2025-01-02至2026-09-30，末日发起清仓。不能清仓的残仓照实保留。
- 初始资金10亿元，单边佣金1bp、卖出印花税5bp；另公开最低佣金5元、过户费0.1bp和滑点假设。
- 10个因子×3个股票池×50/100只×周/月调仓，共120个候选。所有候选均报告2024与2025基准结果；2024入围项另跑零费用、压力费用、关闭滑点、容量收紧和作业延伸。

原始265情景发现末日单日退出仍有大额残仓，随后固定原2024入围参数追加35个后验执行修复情景：提前20/40个源交易日连续退出，并测费用/容量压力。两个阶段不混称预先设计；原265记录不覆盖。修复仅按是否清空选20先、40后的最短成功窗口，不按2025收益选窗口。结果见[2025最终报告](REPORT_2025.md)。

5DR定义为复权收盘价`C[t]/C[t-5]-1`，分别实验正向动量与负向反转；它不自动表示每批股票恰好持有5日。其余包括1日反转、20日动量、60日动量跳过5日、20日低波动、高成交额、低成交额、低振幅，以及反转/低波动等权组合。窗口与方向在研究前固定。

三个选股范围为全部A股、仅主板、当时合格范围中20日均额前1000；均采用有效历史≥120、股价≥2元、20日均额≥2000万元、20日中至少18日有成交。每个信号只使用截至当日数据，绝不采用最后一日存活名单。

2024选型先筛平均仓位≥25%、最大回撤不超过40%、无缺价减记，再按夏普、总收益、实验ID排序；若无人满足，明确记录放宽安全筛选，仍只按2024选择。每个因子独立选择其2024代表参数，分别记录是否触发放宽。2025最高收益项单独标为样本内探索，不替换2024选型冠军。

## ST不能从这些文件准确确定

包内只有OHLC、amt、num_trades、cumadj，没有历史名称或ST身份。真实ST和真实非ST已知覆盖均为0，所有观察保持未知。文件本身也没有官方每日涨跌停价、停牌状态、公司行为明细或开盘竞价深度。

`st_policy=price_proxy`使用截至信号日过去20日的主板接近5%收盘锁板价格特征进行风险筛选。它有误判与漏判，不能识别所有ST，也不能识别通常20%限价的增长板ST。因此工作台始终区分“真实状态未知”与“价格代理排除”，不能把此研究称为已经完成真实ST剔除。

`st_policy=strict`在缺少真实历史标签时明确拒绝运行。`legacy`保留旧口径。

详细数据缺口和243日逐字段覆盖见[包内数据审计](metadata/PACKAGE_ONLY_AUDIT.md)，作业原文与主区间差异见[要求记录](metadata/ISSUE8_REQUIREMENTS.md)。amt在课程中称成交额，但包内没有明确货币单位元数据；以人民币元解释其数值是公开假设。

## 交易与金额口径

新执行模式`daily_conservative`在前一日收盘按当时净资产和价格冻结目标，下一日才尝试成交，不在看到开盘价后重新分配目标。先卖后买，现金不透支，无融资融券；未成交目标保留重试，不买低排名替补。最后一个交易日只尝试卖出。

`wind_down_days=0`保留原末日单日尝试；20/40表示在最后20/40个源交易日期开始，将目标连续设为0并禁止新买。开始日只按预定日历，不依据未来价格或成交额决定；无法成交仍留残仓，不强制清零。正值也请求清算；legacy模式明确不支持正值。

订单受理论板块限价、主板未知ST的半入5%边界、额外4.8%开盘门禁、缺价/无成交、当日复权因子跳变、价格区间及T+1约束。主板/创业板买入100股步长，科创买入至少200股、其上可逐股；完全平仓可能包含合成份额对应的非整数原股等价量，不能当成实物股票交收。

成交量不超过前20日已知均额的1%，并接受当日最终成交额1%的事后安全审计；同一证券当日所有成交累计占用容量。容量收紧场景两项均降到0.1%。当日最终成交额、最高最低价与复权因子跳变属于日终事后信息，不能用它们证明开盘时已知流动性或真实可成交。

买入目标滑点5bp后向上舍入到0.01元，卖出向下舍入，实际滑点可大于5bp。压力情景手续费乘2、目标滑点10bp后再舍入，实际价差不保证线性翻倍。费用按实际本模型成交金额计算：

- `execution_notional = fill_price_raw × raw_share_equivalent`，用于佣金、印花税、过户费与容量。
- `notional = open_raw × raw_share_equivalent`，用于参考开盘金额归因。
- `slippage = abs(fill_price_raw - open_raw) × raw_share_equivalent`。
- `total = commission + stamp + transfer + slippage`。
- 买入现金减`notional+total`；卖出现金加`notional-total`。等价于按真实本模型成交金额收付再扣三项手续费，不能再额外扣一次滑点。

仅有cumadj，持仓采用合成总回报份额，不能拆分现金分红、送转股、分红税和到账延迟。连续缺收盘达到固定天数后减记为0是一项估值情景，不是真实退市清偿。

所有计算采用float64，逐日和账本CSV保存17位有效数字；高显示精度只支持声明模型下复核，不能补出缺失的撮合数据。

## 使用与复现

```powershell
python research.py
python tests/verify_research.py research_outputs/<study_id>
python finalize_research.py research_outputs/<study_id>
python tests/verify_research_strategy.py
python repair_exit.py research_outputs/<study_id>
python tests/verify_research.py research_outputs/<study_id> --repair
python repair_exit.py research_outputs/<study_id> --finalize
```

首个命令会按队列运行完整研究；单项失败记录后继续其余项。`--quick`仅为明确标记的开发小范围运行，不能代替正式120候选结果。Windows研究过程按实际CPU拓扑保留两个性能核心，并限制数值库线程。

每轮生成独立的`research_outputs/study_*/`，包含执行前协议、2025前冻结的选型记录、全部聚合结果及每日路径、入围订单/成交/持仓、局限与验证结果。少量代表策略保留工作台曲线，完整120候选日净值仍在本地runs目录，不把少量曲线当成全网格结果。

精确复现冠军时成对使用研究目录中的`selected_config.json`和`selected_strategy.json`：

```powershell
python run_experiments.py --config research_outputs/<study_id>/selected_config.json --strategy research_outputs/<study_id>/selected_strategy.json
```

`strategies/*.json`只是每个因子的100只/周调仓示意模板，不单独携带完整股票池与执行配置。

研究根下selected_config/strategy保留单日退出原对照；退出补充通过后，已清空冠军对应的成对文件在`feasibility_repair/selected_execution_config.json`和`selected_execution_strategy.json`，其中包含实际wind_down_days。网页完整研究按钮会依次运行原研究、独立验收、退出补充、补充独立验收；任何失败保留证据并显示，不冒充通过。

新增接口：`GET /api/research`读取研究结果；`GET /api/research/download?path=...`下载研究范围内的白名单类型文件；`POST /api/research/run`以`{"confirmed_full_study":true}`启动固定协议完整研究。服务只监听127.0.0.1，无券商或真实订单。

工作台在API与审核快照版本一致时展示结果；后台完成新研究后提示加载新版，避免新数值配旧来源信息。原始行情不重复上传，公开内容限本项目代码、方法、模拟结果和界面截图。
