# 日频多因子回测系统（第二版：策略积木）

一个可在本地浏览器运行、可改参数重跑的课程因子研究系统。默认100万元、目标前100只、每周调仓、仅多头；动量60日跳过5日、反转5日、低波动20日、成交金额20日及固定四因子等权。固定因子方向和窗口，报告全部实验，不按结果择优。

本地页面：**http://127.0.0.1:8776/**。只绑定本机，无券商或真实订单接口。

## 第二版新增

打开 **[策略积木编辑器](http://127.0.0.1:8776/?view=1&tab=strategy-blocks)**，把左侧积木拖进右侧输入插槽，组合评分与筛选条件，然后校验、保存或运行。

- 79个可执行预制模块，覆盖行情、历史滚动、数值运算、横截面、比较、逻辑及常用因子。
- 真实拖拽与嵌套输入；也支持点击/键盘添加、参数修改、输入交换、删除、撤销重做和本机草稿。
- 策略JSON导入导出；自定义积木包JSON导入后可直接拖入策略，积木包只组合白名单运算，不执行Python或JavaScript代码。
- 保存/加载策略，按规则运行三档费用回测；自定义策略名称、结果与下载正常展示，并可从历史实验切回第一版五因子。
- 提供只读AI辅助核对接口（OpenAI兼容协议）；未配置真实模型时清楚标记为本地规则确认。密钥通过启动环境配置，不写入网页或策略文件。
- 运行记录保存完整策略JSON、展开/校验元数据与执行配置，保留原有信号滞后、整手、T+1及成交可行性近似。

格式、模块清单与扩展例子见[V2使用指南](V2_GUIDE.md)。这是Scratch风格的自有策略JSON格式，不宣称兼容`.sb3`文件。界面实测图：[策略积木](dashboard/preview_v2.png) / [自定义回测结果](dashboard/preview_v2_result.png)。

第二版全区间低波动积木示例的1400个交易日净值和现金，与第一版相同规则的结果逐日完全一致，证据见[v2_engine_equivalence.json](v2_engine_equivalence.json)。这说明两种表达方式接入同一引擎，不意味着现实开盘成交已验证。

## 可行性与记账口径

- t日收盘信号，t+1日开盘尝试。因子用原价×当日累计因子计算，按每只股票**首个**有效因子归一化，不依赖未来末日锚点。
- 先卖后买、现金非负、仅多头、T+1；主板买入100股整手，科创买入至少200股且也按100步长取整（比真实200以上逐股申报更保守）。因累计因子无法拆开现金分红和送转股，实际按复权合成份额记账，raw_share_equivalent不是实际交收股票数。
- 开盘相对因子修正前收盘涨幅≥4.8%拒绝买入、跌幅≤−4.8%拒绝卖出。这个统一保守门禁覆盖未知ST的风险，但不是官方板块涨跌停价格模型；其他开盘成交也没有排队/竞价深度证明。
- 全天成交额为0时拒绝成交，是事后日线执行审计代理，不参与因子、选股、替补或参与率，不能证明开盘可成交。未成交目标留待重试、不买低排名替补，持仓数和仓位可能低于目标。
- 按当日开盘估值重标目标份额并近似按开盘成交，是理论执行假设；仍需竞价下单时点、延迟及深度数据。4.8%门禁未精确建模官方0.01元限价舍入，不能保证识别所有ST限价。
- 每笔成交额不超过前20日均额的1%；最低佣金、滑点、按日期变化的印花税和过户费；同时提供零费用、基准、双倍费用/滑点。
- 使用历史全部代码和只依赖过去的动态资格，不用最后一天存活名单。缺收盘先用当日已知开盘，再用旧价；连续缺20个交易日期减记为0，不伪造退市前清仓。缺公司行为、停复牌、ST和退市清偿细节，减记是假设。
- 5日RankIC完整样本对和配对覆盖率，HAC(5)的95%正态近似区间及**原始P**。2024年起单列时间留出观察，不改因子方向、窗口或权重。

## 安装与启动

Python 3.11+（本机验证3.14），`pip install -r requirements.txt`。把课程发布的原始 `feathers.zip` 放在本项目上一层，或设置环境变量指向它：

```powershell
$env:FACTOR_DATA_ZIP = 'D:\quant\feathers.zip'
python run_experiments.py --config config.json --no-build
python server.py --port 8776
```

已有本地环境可用 `powershell -File start.ps1`。首轮本地运行生成于 `outputs/run_20261016_194950_230679/`，不修改原行情或此前复权文件。

网页提供参数表单、归一化净值、回撤、年度表现、IC及费用敏感性、CSV下载。每次回测创建独立运行目录；单个策略失败会记录错误并继续其余队列。结果、配置和冻结协议都可追溯。

Python CLI可独立运行。网页使用Codex Data仪表盘运行时；已编译页面可直接由server提供，**重跑后自动重建网页需要本机已安装Data插件和Node**，否则仍可通过API/CSV取得新结果，但页面保留旧快照并提示加载状态。可通过`FACTOR_DATA_PLUGIN`和`FACTOR_NODE`指定插件及Node。公共仓库只保留本项目的自有界面源码和已编译页面，不复制插件受保护源码。

公共薄源码首次重建时，`bootstrap_dashboard.py`会调用已安装插件的官方preparer，在`.dashboard-runtime`新建完整运行时，再复制自有内容、主题与原快照（恢复原artifact id）并构建；不修改插件或生成项目的受保护文件。可单独执行`python bootstrap_dashboard.py`。

## 验证

```powershell
python -m unittest discover -s tests -v
python tests/verify_real_run.py
```

本地服务启动后可另运行`python tests/verify_api.py`：会真实创建一个短区间自定义回测并更新latest，验证16项接口/重跑/构建行为；完成后需按记录的before_run恢复希望展示的运行。

测试覆盖手算费用与现金对账、拆股净值守恒、信号滞后、未来数据前缀不变、整手、涨幅门禁、拒单不替补、缺价估值、重试和减记。真实结果另核对交易及逐日账本；这些检查验证声明模型下的会计与时序，不代表现实排队成交已验证。

## 文件与接口

- `lab.py`：数据、因子、交易和指标；`run_experiments.py`：冻结协议、15情景、5组IC、报告与网页数据；`server.py`：回环API和静态页面。
- `config.json`：默认参数；`dashboard/src/content/dashboard/`：自有React界面；`dashboard/dist/`：编译结果。
- `GET /api/status`、`GET /api/result`；`POST /api/run`提交参数；`GET /api/download?path=...`下载本次outputs内的白名单类型文件。
- `summary.csv`、`curves.csv`、`yearly.csv`、`ic_summary.csv`为首轮聚合结果；完整本地逐日资金、交易、持仓在对应outputs/base目录。
